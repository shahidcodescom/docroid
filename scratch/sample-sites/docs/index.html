Quickstart Guide

Deploy native Linux microservices and web apps onto mobile hardware with zero configuration.

# Run application in background
docroid run -d -n web-server -p 8080 python3 -m http.server 8080

# Check real-time process metrics
docroid top web-server

Applications execute as isolated processes with process supervision, auto-restarts, and live stdout streaming.
